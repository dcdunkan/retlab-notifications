# ret-nots

> Work in progress.

Self-hostable notification server for [retlab](https://github.com/dcdunkan/retlab).

It's really expensive to run a centralized notification server for everyone.
So, you can deploy one easily and share with others.

Notification servers periodically makes requests to Etlab via retlab on behalf of the authenticated user, and compares the new data with the stored data, and generates notifications and sends it your devices.

More stuff will be documented soon. 
In the meantime, if you want to know more about how it works, read the source code!
